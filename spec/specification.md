I'd like to make a desktop application to manage tasks. 
What I would like is a bulletted list of tasks. If a tabulate a task, it belongs to the one above and is indented. I should be able to minimise that list and just show the parent.
If I complete a task, I would like to mark it as done - it should be struck through.

Optionally the app should be able to decruft (but not delete forever) tasks that are marked as done. So three states to start with: Open, Done (crossed through) and Decrufted (hidden). Perhaps we can have an option to hide or show decruft.

In terms of Backend, I'd like us to support the following for storage:
1. A markdown file on the local filesystem
2. A markdown file in a git repos
3. Possible An Apple Note

The first is the best to start with.

I would like you to develop on the Mac using Swift please.

I'm mindful that this is very much like workflowy as an app, but I don't like subscription applications.
